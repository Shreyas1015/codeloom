# codeloom v0.1 — Plan 3: the dashboard (Home, Journey, Map) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. UI tasks (4–10) also use the `impeccable` skill (craft floor before any UI edit; finish review in Task 11).

**Goal:** `codeloom dashboard` opens a local, live-updating dashboard with the v0.1 screens — Home, Journey and Map — in the approved Gallery Guide design, with its empty, loading, not-indexed and stale states (spec acceptance criterion 5), and updates live when an agent names journeys over MCP (criterion 4).

**Architecture:** A new private workspace package `packages/dashboard` (Vite + React + TS + Tailwind + shadcn/ui + TanStack Router/Query + React Flow + Shiki) builds to static files. `packages/cli` gains `src/web/*`: a dependency-free Node `http` server bound to `127.0.0.1` with a session token, serving those static files, a JSON API that reuses the MCP tool functions (one source of truth for shapes), and an SSE stream driven by `fs.watch` on the `.codeloom` folders. The dashboard never writes; agents write through MCP.

**Tech Stack:** React 19, Vite 7, TypeScript, Tailwind 4, shadcn/ui (Radix), TanStack Router + Query v5, `@xyflow/react` (React Flow 12), Shiki (fine-grained bundle, TS/JS/SQL/JSON only), `@fontsource/schibsted-grotesk` + `@fontsource/jetbrains-mono` (self-hosted fonts). Tests: Vitest + Testing Library (jsdom) for components; vitest for the server; Playwright (Chromium only) for smoke tests on demo-shop.

**Spec:** `docs/superpowers/specs/2026-10-30-codeloom-design.md` §6 (Dashboard: stack, routes, data flow, look, states), §7 acceptance 4–5, §9 (out of scope for v0.1). **Design:** `PRODUCT.md`, `.impeccable/surfaces/dashboard.md` (direction contract), `.impeccable/mocks/screens/codeloom-screens.html` (approved mockups; screens 1 Home, 2 Journey, 4 Map are v0.1).

## Global Constraints

Everything in `.superpowers/sdd/2b/global-constraints.md` still binds (Node ≥ 20 ESM, versioned zod-validated JSON, atomic writes, deterministic sorted output, exit codes 0/1/2, no AI, no work content in fixtures, ask before push/publish, shared-tree git rules: commit with `git commit -m … -- <paths>`, never checkout/reset/stash/restore). Added for Plan 3:

- **v0.1 scope only:** Home, Journey, Map. Tour, Progress, Views, spec badges, notes, "understood %", progress strips and the agent-written tour content are **v0.2/v0.3 — not built and not faked**: no placeholder data, no disabled "coming soon" chrome. Where the mock shows them, the v0.1 screen simply omits them (spec §9).
- **No network at runtime** beyond 127.0.0.1: fonts are self-hosted via `@fontsource/*`, no CDN, no Google Fonts, no telemetry. The browser loads only the local server's origin.
- **Read-only dashboard:** the server exposes GET endpoints and SSE only. No endpoint writes any file. (Naming journeys happens through MCP; the dashboard shows it live.)
- **Security:** server binds `127.0.0.1` only; a random 32-byte session token (hex) is required on every `/api/*` request (cookie `codeloom_session_<port>` — per port, so two dashboards don't log each other out — set by the first `GET /?token=…`, which then 302-redirects to the same path without the token; `HttpOnly; SameSite=Strict; Path=/`), else 401; the `Host` header must be `127.0.0.1:<port>` or `localhost:<port>` (DNS-rebinding guard), else 403; static files are served only from the dashboard dist folder (no path escapes); file contents (code) are served only through `/api/code`, which resolves inside a repo root.
- **One shape source:** API responses are the MCP tool result objects (`workspaceOverview`, `listChains`, `getJourney`, `getNode`, `getNeighbors`, `explainContext`, `indexStatus`, `getLayers`, `search`) plus the few dashboard-only endpoints in the registry. Shared TypeScript types live in `packages/cli/src/web/api-types.ts`; the dashboard imports them type-only (`import type`) via a `codeloom` workspace devDependency.
- **Look:** Gallery Guide tokens as shadcn CSS variables: viridian rail `#1F4D45`, gallery-white ground `#F3F4F1`, ink `#1A1D1C`, ochre stops `#E3A72F`, lanes UI `#2F5E9E` / API `#1F4D45` / DB `#8A5A2B` (queue lane uses the DB umber family, a lighter tint), oxblood `#B5483D` only for errors and broken/unresolved hops. Schibsted Grotesk for UI; JetBrains Mono only for code, paths, lines, routes, SQL. Light theme only. Confidence: `exact` solid, `param` solid-thin, `guess`/unresolved dashed — never presented as fact.
- **Accessibility:** keyboard j/k through journey rows, Enter opens; visible focus rings; every interactive element reachable by Tab; `prefers-reduced-motion` respected; text contrast ≥ 4.5:1 (checked with Impeccable's detector in Task 11).
- **Performance:** Map loads one repo at a time and expands folders on demand (never renders a whole large graph at once); Home lists render ≤ 200 rows then paginate/virtualise.

## Interfaces Registry

```ts
// ---- packages/cli/src/web/server.ts -----------------------------------------------------------
export interface DashboardServerOptions {
  start: string;                 // workspace or repo folder
  port?: number;                 // default: first free port from 4747 upward (try 20), else OS-assigned (0)
  assetsDir?: string;            // default: locateDashboardAssets(); tests pass a temp dir
  token?: string;                // default: randomBytes(32).toString("hex"); tests pass one
  watch?: boolean;               // default true; tests may disable
}
export interface DashboardServer { url: string /* http://127.0.0.1:<port>/?token=<token> */; port: number; token: string; close(): Promise<void> }
export async function startDashboardServer(opts: DashboardServerOptions): Promise<DashboardServer>;

// ---- packages/cli/src/web/assets.ts -----------------------------------------------------------
/** packages/cli/dist/web (bundled, release plan) if it has index.html, else <monorepo>/packages/dashboard/dist.
 * Neither → CodeloomError: 'The dashboard is not built. Run "pnpm --filter @codeloom/dashboard build".' */
export function locateDashboardAssets(): string;

// ---- packages/cli/src/web/events.ts -----------------------------------------------------------
export type ChangeKey = "workspace" | "chains" | "journeys" | `repo:${string}`;   // repo:<id> = that repo's graph/endpoints/summaries
/** fs.watch on <root>/.codeloom, <root>/codeloom.workspace.json and each repo's .codeloom; 250 ms debounce; emits the
 * set of changed keys (sorted). Re-reads the repo list when the workspace file changes. Returns a stop function. */
export function watchMap(start: string, onChange: (keys: ChangeKey[]) => void): () => void;

// ---- packages/cli/src/web/api.ts (all GET; JSON; errors → { error: string } with 400/404/409/500) ----
// /api/overview            → workspaceOverview(start) & { indexStatus: indexStatus(start), mcpConnected: boolean }
//                             mcpConnected = .mcp.json at the workspace root has a codeloom entry (inspectMcp)
// /api/journeys            → { journeys: JourneyRow[], unnamedChains: ChainRow[] }   (dashboard-only, see types)
// /api/journeys/:id        → getJourney(start, id)                 (j_… or ch_…; unknown → 404)
// /api/chains?…            → listChains(start, args)               (query params = ListChainsArgs)
// /api/graph?repo=&dir=    → GraphLevel for one folder level (dashboard-only, see types); repo required
// /api/node/:ref           → getNode(start, ref)                   (ref URL-encoded "repo::nodeId")
// /api/neighbors/:ref?depth=&direction= → getNeighbors(start, …)
// /api/layers?repo=        → getLayers(start, repo)
// /api/search?q=&kinds=&repo=&limit= → search(start, …)
// /api/code?repo=&file=&start=&end= → { file, startLine, endLine, text, truncated } — file resolved inside the repo
//                             root (escape → 400), max 400 lines / 60 000 chars
// /api/events              → SSE: `event: change` `data: {"keys":[…]}`; `: ping` comment every 25 s
// A dataError from the store (not indexed, bad file) → 409 { error: message, code: "not-indexed" | "bad-data" }

// ---- packages/cli/src/web/api-types.ts --------------------------------------------------------
export interface JourneyRow {
  id: string; name: string; area: string; note: string; status: "ok" | "orphaned";
  chainIds: string[]; repos: string[];                 // repos touched by its chains, sorted
  stops: { ui: number; api: number; code: number; db: number; queue: number };
  confidence: "exact" | "param" | "guess";             // worst over its chains
  complete: boolean;                                   // every chain complete
  tables: string[];                                    // sorted
}
export interface ChainRow { id: string; name: string; entry: string; confidence: "exact" | "param" | "guess"; complete: boolean; repos: string[] }
export interface GraphLevel {
  repo: string; dir: string;                            // "" = repo root
  folders: Array<{ path: string; name: string; files: number; layer?: string }>;   // direct child folders, counts are recursive
  files: Array<{ ref: string; path: string; name: string; layer?: string; functions: Array<{ ref: string; name: string; type: "function" | "class"; line?: number }>; journeys: string[] }>;
  edges: Array<{ from: string; to: string; type: string; count: number }>;   // between this level's folders/files (aggregated imports/calls), sorted
}
// plus re-exported result types for the reused MCP functions (OverviewResult, JourneyResult, NodeResult, NeighborsResult, …),
// written as explicit interfaces matching the tool catalogue in the Plan 2b plan.

// ---- packages/cli/src/commands/dashboard.ts ---------------------------------------------------
export async function runDashboard(start: string, opts: { port?: number; open?: boolean }): Promise<DashboardServer>;
// prints: "codeloom dashboard: http://127.0.0.1:<port>/?token=…  (Ctrl+C to stop)"; opens the browser unless --no-open
// (macOS `open`, Linux `xdg-open`, Windows `start ""`; failure → just the printed URL). SIGINT → close → exit 0.
```

### Dashboard-side contract (packages/dashboard)

- `api/client.ts`: `apiGet<T>(path, params?)` — same-origin fetch with `credentials: "same-origin"`; 401 → throws `SessionError`; 409 → throws `MapStateError { code }`; others → `ApiError`.
- `api/queries.ts`: query keys `["overview"]`, `["journeys"]`, `["journey", id]`, `["graph", repo, dir]`, `["node", ref]`, `["neighbors", ref, depth, direction]`, `["layers", repo]`, `["code", repo, file, start, end]`, `["search", q, kinds, repo]`.
- `api/events.ts`: `useMapEvents()` opens `EventSource("/api/events")`; key → invalidations: `workspace` → all; `chains` → overview, journeys, journey/*; `journeys` → overview, journeys, journey/*; `repo:<id>` → overview, graph/<id>/*, node/*, neighbors/*, layers/<id>, code/<id>/*. Reconnects with backoff; shows a quiet "live updates paused" chip when disconnected.
- Routes: `/` Home, `/journeys/$id` Journey (search param `stop=<index>` selects a stop), `/map` (search params `repo`, `dir`, `node`, `overlay=journey:<id>|layer`).
