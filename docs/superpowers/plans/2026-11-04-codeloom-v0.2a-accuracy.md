> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `docs/superpowers/specs/2026-11-04-codeloom-v0.2a-accuracy-design.md`: method nodes + method→method call edges in `graph.json`, more UI calls reaching their page, other-service calls and route ties, Redux / class components / Mongoose shapes — never adding a wrong `exact` link.

**Architecture:** Per-repo `graph.json` is built by the indexer (UA GraphBuilder, tree-sitter structure). The linker already has a per-repo TypeScript code index and a call resolver (`linker/code-index.ts`, `linker/resolve-calls.ts`) that knows class methods and resolves calls with confidence. A new **graph enrichment** step runs after the linker in `codeloom index`: it adds method nodes and `calls` edges from the resolver (exact/param only) to each repo's graph and rewrites it deterministically; chain stops then point at method nodes. UI-reach, other-service, route-tie and framework-shape work extend the existing adapters/linker.

**Tech Stack:** TypeScript compiler API (existing), `@codeloom/core` KnowledgeGraph format, vitest.

### Task 1: Method nodes and call edges in graph.json (spec §1)
- New `packages/cli/src/indexer/enrich-graph.ts`: `enrichGraph(graph, codeIndex, resolver): KnowledgeGraph` — adds a `function` node per class method / object-literal method in the code index (id `function:<file>:<Class.method>`, `name`, `filePath`, `lineRange`, `summary: ""`, `tags: ["method"]`, complexity by line count like functions), `contains` edges file→method (and class→method when `class:<file>:<Class>` exists), and `calls` edges for every caller→callee pair the resolver resolves with `exact`/`param` (`description` = confidence, `weight` 1 / 0.6; duplicates collapse to the best). Existing nodes/edges untouched except that an existing identical `calls` edge is not duplicated. Sorted deterministically; the result parses with `KnowledgeGraphSchema`.
- Wire it into `codeloom index` after `runLinker` (the linker owns the per-repo code index/resolver — expose what's needed from `linker/run.ts`), write each repo's `graph.json` with `writeJsonIfChanged`; `chains.ts nearestNodeId` then finds method nodes (build chains after enrichment, or re-run nodeId lookup against the enriched graph — choose one and document).
- Layers: method nodes get the layer of their file (`detectLayers` re-run or assign by file).
- Dashboard: the Journey inspector's "Call edges for methods aren't mapped yet" note disappears when the stop's `ref` is an exact `function:` node (it already shows Called by/Calls for exact function refs — verify); Map file cards list methods (from `GraphLevel.files[].functions`, which reads graph nodes — verify the builder includes method nodes).
- Tests: demo-shop — `CustomersController.store` node exists and has a `calls` edge to `CustomerService.create`; no edge from a guessed call; determinism (warm/cold byte-identical graph.json); `KnowledgeGraphSchema` parses; chain stop `nodeId` for the handler is the method node; size before/after reported. ### Task 3: Other-service calls and route ties (spec §3)
- `WorkspaceFileSchema` gains optional `external: [{ name: string, apiBase: string[] }]`.
- A UI call whose base is an env var/host that is not the `apiBase` of any workspace repo (and not a relative/same-origin URL) is an **external-service call**: `linkUi` marks it (new target kind or flag); `check` lists it under a new item kind `external-call` ("Calls to other services (N)", grouped by base name or the `external` name), not `ui-no-route`, not counted as broken; `CheckReport.summary.externalCalls`. Dashboard Home/Journey show it as "calls <name>" where relevant (minimal).
- Route ties (`linker/paths.ts` / `pickRoute`): equal-rank matches where one route has a literal segment equal to the call's literal segment at that position → that route wins at `param`; otherwise tie stays `guess`.
- Tests for each; README "Known limits" and workspace-file docs updated; docs test green.

### Task 4: Redux, class components, Mongoose (spec §4)
