# codemap (working name)

Open-source npm package: CodeSee + Understand Anything, connected to Claude / any agent via MCP.

**Start every session by reading `docs/BRIEF.md`** — it holds all research and decisions so far
(CodeSee feature list, Understand Anything capabilities, comparison, architecture, roadmap, the
`feature-tour` prior art, improvement ideas, author preferences).

Rules:
- Personal open-source project, not Acme work — no Jira ticket.
- Re-implement CodeSee features; never copy its code (it was closed source). Understand Anything is MIT —
  forking is fine with the copyright notice kept.
- Ask before any `git push`, `npm publish`, or creating a public repo.
- Outputs for the user: plain, simple language; short and scannable.
