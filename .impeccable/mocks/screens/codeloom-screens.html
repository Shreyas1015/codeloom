CustomerService.create turns the payload into rows

This is where the request stops being JSON. Both inserts run inside one transaction, so a customer is never saved without its contacts. VAT was already checked at stop 4, so create() trusts its input.

17async create(payload: CreateCustomerDTO) {18  return db.transaction(async (trx) => {19    const customer = await Customer.create(payload.customer, { client: trx })20    await customer.related('contacts').createMany(payload.contacts)21    return customer.serialize()22  })23}
Remember this: VAT is validated in the controller, not here. Calling this service from a job skips validation.
